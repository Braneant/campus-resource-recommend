# 前端演示视频

`校园平台-前端模拟演示.mp4` 展示登录、资源广场、个性化推荐、知识图谱、管理端审核和图谱运维页面。视频是使用真实 Vue 前端录制的页面演示；**所有接口响应、身份和资源都是静态模拟数据，没有连接真实后端或数据库，也没有演示真实审核提交、图谱写入或算法结果**。画面底部一直显示该说明。

为了保护现有数据，录制程序拦截全部 `/api/` 请求，并直接拒绝任何非 GET 请求；演示账号只存在于隔离浏览器的 localStorage。视频中的资源、评分与数量仅作界面展示，不是实际测量结果。建议正式招聘展示另行录制隔离后端及数据库的端到端操作。

## 重录方式

在已安装前端依赖的工作区，启动本地前端：

```powershell
cd frontend
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 3398 --strictPort
```

另开终端回到项目根目录，安装或指定本机 Playwright 和 Chromium/Chrome，再运行：

```powershell
$env:PLAYWRIGHT_PATH = '包含 playwright 模块的绝对路径'
$env:CHROME_PATH = '本机 chrome.exe 的绝对路径'
node docs/demo/record.cjs
```

Playwright 需要其视频编码器（`npx playwright install ffmpeg`）。录像存放在 `tmp/engineering/demo-recording/`，用 ffmpeg 转为 MP4，例如：

```powershell
ffmpeg -i <录制的webm文件> -an -c:v libx264 -crf 26 -pix_fmt yuv420p docs/demo/校园平台-前端模拟演示.mp4
```

脚本使用约 18 秒展示每个页面；无需任何真实账号、网络服务或数据库。
