# 推荐效果离线评测

复现：安装 Java 17+ 和 Python 3，执行 `python evaluation/evaluate.py` 与 `python -m unittest discover -s evaluation -p "test_*.py"`。评测调用生产 Java 推荐引擎，输入与结果保存于 evaluation 目录。固定随机种子 20261102，按用户-资源对划分，20% 用户冷启动，其他用户保留约 20% 交互作测试。每一种行为的同一用户/资源对整体划分，训练统计、相似度及热度不使用测试标签。冷启动兴趣取个人专业、学院或目录中固定知识点，而非隐藏交互。图谱由公开种子 Cypher 导出，模型使用同一候选目录。K=10，覆盖率分母为 192 条已审核资源。

| 方法 | 用户 | Recall@10 | NDCG@10 | 覆盖率 |
|---|---:|---:|---:|---:|
| 热度 | 20 | 0.3492 | 0.5465 | 0.1302 |
| ItemCF | 20 | 0.0450 | 0.0293 | 0.3177 |
| 知识图谱 | 20 | 0.2155 | 0.2784 | 0.2917 |
| 混合 | 20 | 0.2255 | 0.3241 | 0.4896 |

冷启动共 4 人：热度、ItemCF、知识图谱、混合的 Recall 分别为 0.3254、0、0.1110、0.2608，NDCG 分别为 0.9185、0、0.3531、0.6590，覆盖率分别为 0.0521、0、0.1667、0.1458。ItemCF 无行为数据时返回空列表。完整分组、数据指纹和每用户排序见 `evaluation/results.json` 和 `evaluation/rankings.tsv`。

这次模拟数据、一次随机切分的测试中，混合模型的召回与 NDCG 低于热门基线，但目录覆盖率较高。20 位评测用户规模很小，冷启动仅 4 位，不能证明真实学生学习效果、统计显著性或线上收益；应进一步采用真实授权数据、时间切分和多次重复实验。该实验不测真实 Neo4j 的延迟。
