2026-11-03 使用 `2f2d3d7` 的全新克隆，构建后端并执行 `npm ci`；独立 MySQL 8 和 Neo4j 2026 使用各自的临时数据目录和本机端口 13316 / 17687，导入仓库模拟数据。Windows 一键启动入口实际执行 `/nopause`，在 8080 / 3000 被占用时选择后端 8081、前端 3001。

- 经前端代理验证学生及管理员登录、资源检索、个性化推荐和知识图谱查询。
- 审核独立数据库中的模拟资源后，检查图谱同步记录成功。
- 关闭独立 Neo4j 后审核另一模拟资源，检查同步失败记录；恢复独立 Neo4j 后重试成功，重复重试保持成功。
- 测试期间真实 MySQL、Neo4j、本项目和实验室系统监听端口保持运行；临时数据库副本及隔离进程已清理。
- `scripts/verify_isolated_e2e.py` 可执行隔离环境的可变更检查。它会审核一条资源，只能在明确确认为临时的独立环境中运行。设置 `CAMPUS_ISOLATED_URL=http://127.0.0.1:<隔离前端端口>` 和 `CAMPUS_ISOLATED_DISPOSABLE=yes` 后执行。脚本严格限制 IPv4 回环并禁用重定向；回环地址本身不能证明目标数据库隔离，操作者仍须核实。
